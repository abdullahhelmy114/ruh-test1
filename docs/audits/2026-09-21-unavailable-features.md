## Production evidence gathered live (main session, read-only)

The sweeps above read the repository; these were measured against the deployed revision itself.
Probes were anonymous GETs, plus empty-body POSTs to public endpoints (no account, payment or
enrollment is created by an empty body — the same probe the HTTP smoke suite uses).

| Probe | Result | Means |
|---|---|---|
| `/academy` | 200, renders `<p role="status">This part of the academy is not available yet.</p>` | `ACADEMY_CORE_SCHEMA_READY` is not `"true"` |
| `/api/public/academy/catalog` | 503 `{"error":"This part of the academy is not available yet."}` | same flag, all 22 services |
| `POST /api/signup/student` (empty body) | **503 `{"message":"Verification service unavailable"}`** | **`INTERNAL_API_SECRET` is unset — nobody can register** |
| `POST /api/signup/teacher` (empty body) | **503 same** | same secret, both sign-up paths |
| `POST /api/cloudinary/sign-upload` `{"purpose":"teacher_cv"}` | **503 `{"error":"Upload service unavailable"}`** | **Cloudinary unset — a teacher application cannot upload its required CV** |
| `POST /api/send-verification-code` (empty body) | 400 `Missing email` | validates first; same secret is checked at route.ts:54 |
| `/api/words`, `/api/irab`, `/api/quran-irab`, `/api/library/books`, `/api/categories`, `/api/course` | 500 | their legacy tables are absent |

| `/api/courses`, `/api/bundles` | 410 | retired, as intended |
| 20 public routes sampled | all 200 | no 5xx on the public launch path |

Ordering note: the sign-up 503 is checked **before** any side effect, so no Firebase account or profile
is created by a failed attempt. Sign-up is blocked, not corrupting.

## Two prerequisites that outlast the flag

Enabling `ACADEMY_CORE_SCHEMA_READY` is necessary but **not sufficient**:

1. **No policy has a default.** `src/lib/academy/policies/registry.ts` defines 13 policies and none carries a
   default, and no migration seeds `academy_policy_values`. Services fail closed with `POLICY_UNCONFIGURED`
   ("This academy setting has not been configured yet."). `institution.timezone` gates the Lesson Sheet release
   window, so lesson sheets stay unavailable until an administrator sets the policies in `/academy/manage/policies`.
2. **The catalog will be empty.** With the flag on and nothing published, `/academy` correctly shows
   "No courses are open yet. Please check back soon." (`src/app/academy/page.tsx:56`) — an empty catalog, not a fault.
